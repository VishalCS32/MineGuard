Tilt here is raw — no commissioning baseline and no thermal correction — so it mostly describes how each post was hammered in. It is the right number for “this node is reporting” and the wrong one for “this node is in trouble”; that judgement is made by the backend, which has the baselines and the whole array. Written to NVS. Saving WiFi credentials joins that network immediately — watch the Network card above for the result — and the page stays reachable on this access point either way. The backend URL receives raw protocol frames and is the system of record; the realtime push URL is optional and receives a decoded JSON document of the gateway and every node it has heard, every ten seconds, for anything else that wants the data.
